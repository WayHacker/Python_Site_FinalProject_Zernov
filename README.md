## О проекте

Бэкенд веб-сайта для аренды одежды. Пользователи могут размещать объявления
о сдаче одежды в аренду, искать подходящие варианты по фильтрам, связываться
с владельцами и оставлять отзывы.

Проект выполнен в рамках дипломной работы по курсу «Python-разработчик».

## Функционал

- **Аутентификация** — регистрация, вход, выход. Кастомная модель
  пользователя с телефоном и аватаром.
- **Размещение объявлений** — описание, размер, бренд, стоимость аренды,
  залог, местоположение, контактные данные, фото.
- **Поиск** — по ключевым словам в заголовке/описании, по городу,
  по диапазону цен.
- **Редактирование и удаление** — только владелец объявления может
  редактировать или удалять свои объявления.
- **Модерация** — новые и изменённые объявления попадают на модерацию
  и публикуются только после одобрения администратором.
- **Отзывы** — авторизованные пользователи могут оставить отзыв (1–5 звёзд
  + текст) на чужое объявление. Один отзыв на объявление от одного
  пользователя.
- **Скрытие контактов** — телефон и email владельца видны только
  авторизованным пользователям.
- **Пагинация** — список объявлений разбит на страницы.

## Технологии

- Python 3.12
- Django 6
- PostgreSQL 16
- Docker + docker compose
- pytest + pytest-django
- Gruvbox Dark (CSS-тема, без Bootstrap)

## Запуск через Docker (рекомендуется)

Требования: Docker и Docker Compose.

```bash
# 1. Клонировать репозиторий
git clone https://github.com/WayHacker/Python_Site_FinalProject_Zernov.git
cd Python_Site_FinalProject_Zernov

# 2. Скопировать шаблон окружения
cp .env.docker.example .env.docker

# 3. Поднять контейнеры
docker compose up --build

# 4. В новом терминале создать суперпользователя
docker compose exec web python manage.py createsuperuser
